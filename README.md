# 🛼 Snitap — Patins com animações

Projeto desenvolvido por mim durante os estudos na Rocketseat, utilizando HTML e CSS para criar uma página de apresentação de patins com foco em animações, transições e efeitos visuais.

## 🌐 Acesse o projeto

[🔗 Visualizar o Snitap](https://carlosleonello.github.io/patins-animation/)

## 💻 Sobre o projeto

O Snitap é uma landing page que apresenta patins e uma galeria de fotos, explorando diferentes formas de criar movimento e interação com CSS.

A página reúne:

- Cabeçalho com efeitos de rotação no logo e no ícone da sacola.
- Título com alternância animada entre as palavras “radical”, “divertida” e “saudável”.
- Animação de entrada dos patins e dos elementos decorativos.
- Botões com efeitos ao passar o mouse.
- Faixa com movimento contínuo e fundo em gradiente animado.
- Galeria com quatro fotos organizadas em CSS Grid.
- Efeito de zoom e exibição do perfil nas fotos ao passar o mouse.
- Animações de entrada das fotos acompanhando a rolagem da página.
- Rodapé com efeitos nos links de navegação e nos ícones das redes sociais.

## 🚀 Tecnologias utilizadas

- **HTML5** para estruturar o conteúdo da página.
- **CSS3** para criar o layout, as animações e os efeitos visuais.
- **Google Fonts** para utilizar as fontes Montserrat, Syne e Inter.
- **GitHub Pages** para publicar o projeto.

## 📚 Conceitos praticados

Durante o desenvolvimento, pratiquei:

- Organização de elementos com Flexbox e CSS Grid.
- Definição de áreas do layout com `grid-template-areas`.
- Uso de variáveis CSS para cores e tipografia.
- Criação de animações com `@keyframes` e `animation`.
- Transições entre estados com `transition` e `:hover`.
- Transformações com `translate`, `scale` e `rotate`.
- Animações vinculadas à rolagem com `animation-timeline: view()` e `animation-range`.
- Seletores aninhados com CSS Nesting e `&`.
- Criação de efeitos com os pseudo-elementos `::before` e `::after`.
- Posicionamento de elementos e sobreposição de legendas nas imagens.
- Separação do CSS em arquivos por seção da página.

## ▶️ Como visualizar localmente

1. Clique em **Code → Download ZIP** neste repositório.
2. Extraia os arquivos.
3. Abra o arquivo `index.html` no navegador.

Também é possível abrir a pasta no VS Code e visualizar a página com a extensão **Live Server**.

Não é necessário instalar dependências.

## 📝 Observações

Este é um projeto educacional, desenvolvido com foco em desktop.

Os botões de compra e vídeo, os links de navegação e os ícones de redes sociais são demonstrativos e utilizam `href="#"`.

O projeto utiliza recursos modernos de CSS. A exibição de alguns efeitos, especialmente as animações vinculadas à rolagem, depende do suporte do navegador.
